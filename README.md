# Techzaster

Static GitHub Pages version of the Techzaster website.

Includes:
- Home
- Socials
- My Collection

The forum and Node.js backend are intentionally not included.


## Visit counter

The site now has a global page-view counter in the top-right of the header.

It uses CounterAPI because GitHub Pages is static and cannot store a shared counter itself. CounterAPI currently provides a free tier with no credit card required.

To activate the counter:
1. Create a free CounterAPI account/workspace.
2. Create/use the workspace name `techzaster-site`.
3. Keep the counter name `page-views`.
4. Upload the files in this ZIP to GitHub Pages.

The counter increments once whenever the site page loads. It is a total page-view counter, not a unique-visitor counter.
